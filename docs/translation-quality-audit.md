# 翻訳品質監査 — 現在の候補一覧

## 目的

`data/tags.json`の既存訳を自動で上書きせず、翻訳品質を人が確認するための候補を抽出します。候補に入ったことは誤訳の確定を意味しません。

## 現在の監査結果

- 対象タグ：11,047件
- 要確認候補：574件（理由は重複するため合計と一致しません）
- `japanese-translation-missing`：186件
- `english-remains-in-japanese`：385件
- `likely-literal-or-machine-translation`：1件
- `same-as-latin-tag`：8件

これまでに73件の訳語を修正し、すべて変更履歴へ記録しました。これらは自動修正のため、確認台帳では人手の最終確認待ち（`needs-review`）です。候補の一覧は [data/translation-audit-candidates.json](../data/translation-audit-candidates.json) です。各項目は英語タグ、現行訳、分類、検出理由、確認状態を持ちます。`proposedJa`は意図的に空（`null`）にしており、未検証の自動訳を正解候補として提示しません。

## 検出ルールと限界

- 日本語訳の空欄を抽出します。
- 日本語訳にラテン文字が残っている項目を抽出します。作品名・キャラクター名・ブランド名など正当な表記も含まれるため、誤訳とは断定しません。
- 現データで確認された機械翻訳らしい特定表現を抽出します。ルールは発見済みの例に限定され、全種類の誤訳を検出するものではありません。
- 英語タグと同一のラテン文字訳を抽出します。略称・固有名詞では妥当な場合があります。

この監査は候補抽出であり、意味を理解した全件校正ではありません。候補外のタグにも誤訳は残り得ます。

## 再生成とCI

タグデータを変更した後、以下を実行します。

```sh
node scripts/audit-translations.mjs --write
node scripts/audit-translations.mjs
```

通常実行は候補一覧が最新かを検証します。翻訳候補の修正・確認は [タグデータ管理ガイド](tag-data-management.md) の手順に従い、確定した訳だけを本体へ反映してください。
