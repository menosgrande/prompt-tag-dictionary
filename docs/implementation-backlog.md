## 完了報告の要件

各作業では次を記録します。

- 取得した正本のコミットまたはBlob SHA
- 対象範囲・対象件数
- 変更ファイルと変更内容
- タグ件数・未分類件数・各レビュー状態の変更前後
- 実行したテスト・監査コマンドと結果
- GitHub Actionsの実行状態（該当する場合）
- 未解決事項と保留理由

未実施のテストを成功扱いにしない。ブラウザ操作をしていない場合は、実ブラウザ確認済みと記載しない。
