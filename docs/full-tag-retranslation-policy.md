# 全タグ再翻訳・再分類の確定方針

更新日: 2026-10-30
対象: `data/tags.json`（監査時点で11,047件）

## 基本原則

既存タグは完成済み辞典ではなく、再編集のための素材として扱う。旧分類・旧小分類・旧日本語訳は正解として引き継がず、新しい10大分類を基準に再構成する。旧分類は参考情報にとどめる。

## 全件再翻訳

- 11,047件すべての日本語訳を、英語タグを原文として再検討する。
- 既存訳の単なる校正ではなく、必要なら一から訳し直す。
- 固有名詞は作品・キャラクターの正式な日本語表記を優先する。明らかな誤訳（例: ウマ娘のキャラクター名を「金船」とする誤変換）は修正する。
- 直訳調、機械翻訳調、意味のずれ、検索しにくい表現を修正する。
- 画像生成での用法を踏まえ、短く意味の伝わる日本語にする。
- 全件を一括処理し、途中で分野ごとの確認を何度も挟まない。
- 判断に迷うものだけを未分類／要確認としてまとめ、判断理由も記録する。確信のない訳や分類を推測で確定しない。

## 括弧書きタグ

- 括弧書きが作品名・シリーズ名・キャラクター名を示す形式は、基本的にアニメ・漫画・ゲーム等の作品系として扱う。
- 例: `Character (Series)`、`Series (Character)`。
- 括弧があるだけで機械的に作品系へ分類せず、英語タグと括弧内外の意味を確認する。
- 括弧が別名・読み・説明・属性を示す場合は、その意味に従う。

## 再分類・整理

- 新しい10大分類と小分類を正として全件を再分類する。
- 必要に応じて訳語の修正、属性分離、意味的重複の整理を行う。
- 色属性はタグ本文と独立したメタデータとして扱い、意味を損なわない複合タグだけを分離する。
- 作品名・キャラクター名・慣用表現は機械的に分解しない。
- 意味分類とpositive / negativeの出力先は独立させる。意味上は人物・構図などに属するタグを、出力先がnegativeという理由だけで「ネガティブ」分類へ移動しない。
- 既存のデータ形式を維持すること自体は要件ではない。追跡可能性と移行安全性を確保しつつ、辞典として扱いやすい構造を選ぶ。

## 完了時の成果物

各タグについて、英語タグ、日本語訳、新10分類・小分類、出力先、必要な作品・キャラクター階層や色属性、確認状態を確認できるようにする。

全件処理後は、確定件数・未処理件数・未分類／要確認件数を明示し、判断が残ったタグだけをまとめて提示する。全件完了を装わない。
