# 辞典再構築・確定済み方針と旧データ監査

更新日：2026-11-03  
状態：ユーザー回答で確定したルールと、未承認の設計案を分離した作業基準。

## 確定した収録・整理ルール

- 色だけが異なる複合タグを別々に登録しない。
- 色語を除いても対象の意味が成立する場合、色を除いた基本語だけを収録する。例：`red hair` → `hair`。
- 色を独立属性として保持しない。辞典から生成するプロンプトにも、色付き派生タグを出力しない。
- 色語を除くと別の意味になる既成語、固有名詞、食品名、動植物名、模様名、素材名などは原形維持候補とし、機械的に基本語へ変換しない。
- 色指定が必要な場合、利用者が辞典外のプロンプト欄で自由に追加できる。
- 作者・ブランド・団体は「キャラクター・作品」内の小分類とする。
- 食べ物・飲み物は「家具・設備・物品」内の小分類とする。
- 成人向け区分、確認状態、Positive / Negative出力先は意味カテゴリではなく横断属性として扱う。
- 同義語と、上位・下位・関連語は別の関係として管理する。
- 分類確定前に公開用JSONやPagesへ反映しない。

## 原形維持31件について

原形維持は「必ず公開採用」ではなく、色を取り除かず個別の意味単位として扱う候補という意味である。例：
- 固有名詞・作品名候補：`blue archive`、`red cross`、`red oni`
- 定着表現・食品名：`blue hour`、`green tea`、`red carpet`、`red wine`、`white day`
- 動植物・名称：`blue oak`、`white snake`、`white tiger`
- そのほか `black vs white` など、色語自体が対比の意味を持つ表現

個々の採用可否は、タグの実際の用法・出典・翻訳を確認して決める。

## 旧データ移行時の必須処理

1. 旧タグを原文のままバックアップし、参照可能にする。
2. 色付きタグの基本語候補を抽出し、既存基本語との重複を照合する。
3. 基本語が存在しない場合は、自動生成せず意味・訳・分類を確認する。
4. 原形維持候補は固有名詞・既成語・食品・動植物・模様・素材などの意味を確認する。
5. 同じ英語タグの重複、別名、誤訳、誤分類を別々の監査項目として処理する。
6. 要確認状態のレコードは公開データへ確定採用しない。

## データ設計上の注意

色語を分離して保持する旧案は、上記の確定方針と矛盾するため採用しない。旧案にある「元タグを保持し、対象語と色値を分離する」記述は本書で撤回する。新スキーマには色値フィールドを設けない。

本書は確定済み方針を記録するものであり、未確定のカテゴリ案やスキーマを承認済みにするものではない。
