# 小分類102区分の実データ照合監査 v1

更新日：2026-11-03  
対象：旧タグ10,988件、旧小分類49区分、新カテゴリ案17区分・新小分類102区分  
状態：旧データとの照合に基づく見直し提案。新タグの確定移行は未実施。

## 結論

**102小分類は初期案としては細かすぎる可能性が高い。** ただし、旧データの分類が大きく崩れているため、旧小分類の件数をそのまま新小分類の必要件数とみなして削るのも不適切。現段階ではカテゴリの意味境界を維持しつつ、UI上は小分類を必要に応じて表示し、タグ移行時に実データの偏りを確認してから統合する。

旧データ10,988件のうち、3,318件が未分類、1,085件が「その他」、774件が「光・色彩」、285件が旧「成人向け」に入っている。特に旧分類の意味が混在しているため、単純な件数ベースの小分類統合は避ける。

## データ照合で分かったこと

### 旧分類の大きな問題

- 旧「光・色彩 / 色」702件には、色名だけでなく `black apron`、`black background`、`black bird` のような色付き複合語や、`akane (blue archive)` のような固有名詞も混在する。
- 旧「光・色彩 / 色調」25件には、`monochrome`、`sepia`、`two-tone background` などがある。ユーザー方針では色そのものを辞典データとして保持しないため、色を含むだけで機械的に削除せず、色が意味の核となる語か、描写技法・既成表現かを確認する必要がある。
- 旧「成人向け / 身体・衣類」257件には、`2boys`、`adjusting panties`、`after sex` など性質の異なるタグが混在する。成人向けカテゴリは廃止し、意味分類とratingを別々に判定する。
- 旧「その他 / 記号・効果」127件には、句読記号・ロゴ・音楽記号だけでなく、`afterglow`、`aura`、`blood` など視覚効果・状態を示す語も含まれる。
- 旧「その他 / 自然物」65件には植物・食品・天体・自然現象が混在する。
- 旧「その他 / 物」573件には楽器、武器、乗り物、旗、家具、装飾品などが混在する。新分類では物品・乗り物・文字記号・生物・背景へ振り分ける必要がある。
- 旧「人物 / 身体・部位」329件には身体部位だけでなく、`arm around waist` のような動作・接触表現も混在する。
- 旧「服装 / 小物」294件には衣服に付属する装飾だけでなく、`backpack` のような物品や、`adjusting eyewear` のような動作表現も含まれる。

## 小分類の見直し提案

### 1. まず維持する小分類群

以下は検索意図が明確に異なるため、現時点で統合しない。

- キャラクター・作品：作品・シリーズ／キャラクター／作者・制作者／ブランド・団体
- 人物・顔・髪：人物属性／顔パーツ・表情／髪型・頭部装飾
- 服装：上半身／下半身／全身衣装／下着・水着／靴／アクセサリー／装着装備
- 背景：室内／建物・施設／都市空間／自然地形／空・宇宙／時間・季節・天候
- 構図：ショットサイズ／カメラ角度／視点／フレーミング／レンズ／被写界深度／パース
- 画風：アニメ・漫画／イラスト・絵画／写真・写実／3D・CG／画材／線画・塗り／質感・技法

### 2. 統合候補

| 現行小分類 | 統合案 | 理由 |
|---|---|---|
| ポーズ：立つ・歩く／座る・しゃがむ・跪く／寝る・横たわる | 「姿勢・移動」にまとめ、必要ならタグ属性・検索語で細分 | 旧データは姿勢小分類40件で、細分を支えるデータ量がまだ不明。 |
| ポーズ：手・指・腕／脚・足 | 「身体部位の動作」にまとめる案 | 旧データで細分が極端に少なく、UIで分ける必要性を実データで再評価。 |
| 光：光源・照明／光の方向・質 | 統合せず維持を基本。件数が少なければ表示上まとめる | 意味の違いは明確で、照明タグが増えた場合に有効。 |
| 光：発光・光線／レンズ効果・画面効果 | 「発光・光学効果」に統合する案 | タグの意味領域が近く、利用者の検索目的も重なりやすい。 |
| 生物：爬虫類・両生類・昆虫 | 「その他の動物」にまとめる案 | 旧データの生物分類が不十分で、独立小分類の需要をまだ確認できない。 |
| 生物：生物の部位・状態 | 対象生物の小分類へ統合する案 | 部位・状態は生物種をまたぐ横断軸であり、意味分類と属性が混在する可能性。 |
| 物品：家電・設備／家具・室内用品 | 初期は統合も可能 | タグ数と検索導線を見て決定。建物・場所とは区別する。 |
| 物品：日用品・小物／その他の物品 | 「一般物品」に統合する案 | 「その他」は恒久的な受け皿になりやすいため、内容が増えた段階で具体化。 |
| 乗り物：鉄道・地上交通／自動車・二輪車 | 「陸上交通」にまとめる案 | 小分類の表示を簡潔にできる。乗り物タグ数を確認して最終決定。 |
| 文字：数字・記号／図形・マーク | 統合候補 | 文字・記号のタグ数と検索利用を見て決定。ロゴ・看板・吹き出し・UIは用途が異なるため維持。 |

### 3. 小分類ではなく属性・関係として扱うべきもの

- Positive / Negative：`promptTarget` 属性。
- 成人向け表示：`rating` 属性。
- 確認済み／暫定／要確認：`reviewStatus` 属性。
- 色：独立属性として保存しない。色だけの修飾は基本語へ統合する。
- 同義語・表記揺れ：`aliases`。
- 上位語・下位語・関連語：関係データ。
- 作者・ブランド・団体：独立大分類にせず「キャラクター・作品」の小分類。
- 食品・飲料：独立大分類にせず「家具・設備・物品」の小分類。

## 102小分類の現時点での扱い

102という数を目標値にしない。次の原則で確定する。

1. 1小分類に十分なタグがあるかだけでなく、検索意図が独立しているかを重視する。
2. 件数が少なくても、概念が明確で検索目的が異なるものは維持できる。
3. 概念が近い小分類は、タグ件数が多くても統合できる。
4. 小分類の下にさらに階層を増やさない。初期は大分類→小分類の2階層に限定する。
5. タグが0件の小分類は削除確定せず、未使用候補として記録する。
6. 「その他」「未分類」を恒久的な分類として増やさない。未確定はreviewStatusで管理する。
7. 1タグ1大分類を維持し、重複登録で検索性を補わない。
