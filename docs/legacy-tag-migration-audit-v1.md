## 自動移行してよい範囲

次の条件をすべて満たすレコードだけ、初回の機械移行候補にする。

- 旧小分類と新分類の意味が一対一で対応している。
- タグ自体が一般語として明確で、固有名詞・複合語の解釈が不要。
- 色正規化・重複統合・成人向けrating判定など、別監査が必要な対象ではない。
- 日本語訳に明らかな意味不一致がない。
- 新小分類まで安全に決められる場合のみsubcategoryIdを設定する。判断できない場合はnullではなくneeds_reviewを検討する。

この条件を満たさないレコードは、旧分類を仮の手掛かりとして保持し、タグ単位で確認する。旧分類を根拠に無理に確定しない。

## 重要な移行上の注意

- 旧「成人向け」は新しい意味カテゴリとして残さない。ratingは別属性だが、個々のタグのratingを旧分類だけから一括決定しない。
- 旧「光・色彩 / 色」は色正規化監査結果を適用する。ただし基本語が旧データに存在するか、意味・訳・新分類が適切かを照合する。
- 旧「その他」は恒久カテゴリへ移さない。小分類・タグの意味を見て新分類へ振り分ける。
- 旧「未分類」は3,318件ある。ここを一括で「その他」に移す処理は禁止。
- 移行中は元レコードのtag / ja / category / subcategoryを追跡できる対応表を保持する。
- この表は初期マッピング候補であり、10,988件の移行完了を意味しない。
