# 色付きタグ整理の予備監査

最終更新: 2026-10-31

## 目的

色名が先頭に付いたタグを、色違いグループUIではなく、色を除いた基本概念の意味カテゴリへ整理できるか調査する。元タグ・日本語訳は保全し、固有名詞・作品名・慣用表現・色が意味の識別に必要なタグは機械的に変更しない。

## 予備抽出結果

`data/tags.json`（11,047件）を対象に、次の色語が先頭にあるタグを抽出した。

black, white, red, blue, green, yellow, orange, purple, pink, brown, grey, gray, blonde, blond, silver, gold, beige, cream, cyan, magenta, teal, navy, ivory, maroon, lavender, turquoise

- 抽出候補: 918件
- 既存分類などを参考に分類先候補を提示: 591件
- 基本概念・分類先の確認が必要: 299件
- 固有名詞等の可能性があり個別確認・保護対象: 18件
- 色の意味を残すべき候補（肌など）: 10件

この件数は先頭一致の予備抽出であり、全ての色関連タグを網羅した確定件数ではない。複合色（例: light blue）や色語が後置されるタグは別途監査が必要。

## データの扱い

- `data/color-tag-cleanup-candidates.json` は監査候補の派生データであり、確定済みの変換表ではない。
- `data/tags.json` の原タグ・日本語訳・分類はこの工程では変更していない。
- `base` が既存タグに一致しても、意味が一致するとは限らない。分類先は提案値であり、自動確定しない。
- 括弧付き表現や固有名詞らしい語は自動変換対象から外す。
- 肌・人種・種族・キャラクター識別など、色を除くと意味が変わる可能性があるタグは保持または個別確認する。
- 元の色付きタグをプロンプト出力で別タグへ置換しない。基本概念タグへ集約する最終仕様は、候補の意味監査後に決める。

## 次の工程

1. 色語の位置・複合色・括弧付きタグを含めて抽出範囲を拡張する。
2. 591件の分類候補を意味カテゴリ単位で監査する。既存分類の誤りをそのまま引き継がない。
3. 299件の未確定候補と18件の保護候補を個別確認する。
4. 元タグを保持したまま、辞典表示・検索・選択・プロンプト出力をどう対応させるか設計する。
5. 確定した差分のみを別データとして管理し、元データを一括破壊しない。
