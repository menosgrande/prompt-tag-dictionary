# ローカル管理画面

`admin.html` は `data/dictionary-data.json` を直接読み込むローカル編集画面です。

## できること
- 英語タグ・日本語訳・分類・詳細・別名の検索と編集
- 翻訳・分類それぞれの確認状態、修正理由、出典の記録
- 変更差分の表示
- この端末のローカルストレージへの下書き保存
- 正本JSON全体の一括エクスポート

## データの扱い
- 管理画面が読み込むデータファイルは `data/dictionary-data.json` のみです。
- 確認状態は各タグ行の第7項目 `review` に保存します。独立した `tag-review.json` は使いません。
- プロンプト出力順も正本内の `promptOrder` を編集します。
- エクスポート適用時に更新するファイルは `data/dictionary-data.json` のみです。
- `data/tag-change-log.json` は旧変更履歴の監査アーカイブで、管理画面からは更新しません。

## 操作手順
1. `admin.html` を開く。
2. タグを検索して選択する。
3. 必要な項目を編集し、差分を確認して「変更を保存」。
4. 「一括エクスポート」で `dictionary-data-admin-export.json` を保存する。
5. リポジトリのルートで `node scripts/apply-admin-export.mjs --input dictionary-data-admin-export.json --check` を実行する。
6. 検証が成功した場合だけ `--write` を付けて正本へ反映する。

## セキュリティ上の制約
- **この画面には認証・アクセス制御がありません。** URLを知る人は画面を開けます。秘密情報やトークンを入力しないでください。
- ローカル保存は現在のブラウザ・端末に限られます。
- GitHubへの直接書き込みや自動公開は行いません。
- 古いローカル下書きは正本フィンガープリントが一致しない場合に復元しません。
- 確認状態を「確認済み」にするのは、根拠を実際に確認した場合だけにしてください。
