# ローカル管理画面

`admin.html` は、タグデータをブラウザから編集するための初期管理画面です。

## できること
- 英語タグ・日本語訳・分類を検索して編集
- 翻訳・分類の確認状態、修正理由、出典URLを記録
- 変更前後の差分を表示
- 編集内容をブラウザのローカルストレージに保存
- `tags.json`、`tag-review.json`、`tag-change-log.json` を個別に出力

## 重要な制約
- **この版には認証・アクセス制御がありません。** URLを知る人は画面を開けます。秘密情報を入力しないでください。
- ローカル保存は現在のブラウザ・端末に限られます。
- GitHubへの書き込みやサイトへの自動公開は行いません。
- 出力したファイルをそのまま上書きする前に、差分と監査結果を確認してください。
- `tag-change-log.json` は追記型の運用を前提としています。複数端末の編集を統合する場合は、変更の重複・欠落を確認してください。
- 確認状態を「確認済み」にするのは、根拠を実際に確認した場合だけにしてください。

## 操作手順
1. GitHub Pagesで `admin.html` を開く。
2. タグを検索して選択する。
3. 必要な項目を編集し、差分を確認して「変更を保存」。
4. 編集後に必要なJSONを出力する。
5. リポジトリへ反映する前に `node scripts/audit-tags.mjs` と `node scripts/audit-tag-management.mjs` を実行し、PRで確認する。

次段階ではGitHub認証を利用してPRを作成する連携を検討します。ブラウザにPATを埋め込む方式は採用しません。


## タグの直接編集

英語タグ名・詳細分類・別名を含む編集は、管理画面上部の「辞典の直接編集を開く」から行います。通常の辞典画面には編集操作を表示しません。直接編集画面での変更は `ptd.dictionary.v1` に保存され、公開データは自動更新されません。必要に応じて編集済みタグJSONを書き出して確認・統合してください。

**注意:** `?admin=1` は編集UIを表示するためのモード指定であり、認証・アクセス制御ではありません。GitHub Pagesの静的サイトでは、URLを知る利用者による画面表示を防げません。


## NSFW・年齢レーティング候補の確認

管理画面下部の「NSFW・年齢レーティング候補」では、`data/nsfw-prompt-tag-audit.json` の監査候補を読み込み、NSFWと年齢レーティングを別々に確認できます。

- 監査データの候補値と、管理者が選択した確定値を分離します。
- NSFW確定値は true / false / 未判定、年齢レーティングは 全年齢 / R-13 / R-15 / R-18 / 未判定 から選択します。
- NSFW確認状態とレーティング確認状態も独立して管理します。
- 編集内容は既存の管理画面ドラフトと同じく、この端末のローカルストレージに保存されます。
- 「メタデータ確認台帳を出力」で `tag-metadata-review.json` を出力できます。
- この操作は `tags.json`、`tag-review.json` を変更せず、GitHubや公開サイトへ自動反映しません。

**注意:** 「確認済み」は内容を実際に確認した場合だけ選択してください。NSFW候補値は自動判定の確定結果ではありません。年齢レーティングも初期状態ではすべて「未判定」です。
