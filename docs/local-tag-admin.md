# ローカル管理画面

`admin.html` は、タグデータをブラウザから編集するための初期管理画面です。

## できること
- 英語タグ・日本語訳・分類を検索して編集
- 翻訳・分類の確認状態、修正理由、出典URLを記録
- 変更前後の差分を表示
- 編集内容をブラウザのローカルストレージに保存
- `tags.json`、`tag-review.json`、`tag-change-log.json` を個別に出力

## 重要な制約
- **この版には認証・アクセス制御がありません。** URLを知る人は画面を開けます。秘密情報を入力しないでください。
- ローカル保存は現在のブラウザ・端末に限られます。
- GitHubへの書き込みやサイトへの自動公開は行いません。
- 出力したファイルをそのまま上書きする前に、差分と監査結果を確認してください。
- `tag-change-log.json` は追記型の運用を前提としています。複数端末の編集を統合する場合は、変更の重複・欠落を確認してください。
- 確認状態を「確認済み」にするのは、根拠を実際に確認した場合だけにしてください。

## 操作手順
1. GitHub Pagesで `admin.html` を開く。
2. タグを検索して選択する。
3. 必要な項目を編集し、差分を確認して「変更を保存」。
4. 編集後に必要なJSONを出力する。
5. リポジトリへ反映する前に `node scripts/audit-tags.mjs` と `node scripts/audit-tag-management.mjs` を実行し、PRで確認する。

次段階ではGitHub認証を利用してPRを作成する連携を検討します。ブラウザにPATを埋め込む方式は採用しません。
