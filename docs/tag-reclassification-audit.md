# Tag Reclassification Audit — Baseline and Migration Plan

対象: `menosgrande/prompt-tag-dictionary`
基準ブランチ: `main`
監査対象: `data/tags.json`, `data/prompt-order-categories.json`, `src/app.js`, `src/admin.js`, `admin.html`
方針: 新しい10分類の設計を正とし、既存分類への互換性より辞典としての意味的な正確性を優先する。

## 1. 監査ベースライン

main の現行データを読み取り、以下を確認した。

| 項目 | 結果 |
|---|---:|
| タグ総数 | 11,047 |
| 既存配列形式 | 全件4項目 |
| 未分類 / 未分類 | 5,161 |
| 旧「画風・品質」大分類 | 152 |
| 旧「画風・品質 / 品質」 | 35 |
| 日本語訳が空欄または英語タグと同一 | 187 |
| 英語タグの重複（前後空白除去・小文字化で比較） | 0 |
| ネガティブ出力指定 | 25 |
| 出力カテゴリ定義 | 9カテゴリ |
| 旧検索カテゴリ定義 | 12大分類 |

注:
- 重複0件は英語タグの単純な正規化一致のみを対象とする。意味的な重複・表記揺れ・別名は未監査。
- 日本語訳187件は「空欄または英語タグと完全一致」の件数。訳の正確性や自然さは別途監査が必要。
- 未分類5,161件には記号・顔文字・作品名・人物名・一般タグが混在している。全件を一律に意味分類へ押し込まず、検索補助用の特殊タグや要確認を認める。
- 現行4項目配列は維持する。新しい属性は原則として別メタデータで管理する。

## 2. 確認された構造上の問題

1. `src/app.js` の検索分類 `CATEGORIES` は旧12大分類を保持している。
2. `data/prompt-order-categories.json` は出力用9カテゴリを保持している。
3. `src/admin.js` にも出力カテゴリの既定順が独立定義されている。
4. 検索画面では「品質・スコア」を独立表示する一方、旧「画風・品質」も残り、品質の入口が二重化している。
5. 出力処理はカテゴリ別出力時にカテゴリ順を参照するが、カテゴリ別出力を無効にした場合は選択順が残り、品質タグ先頭を保証しない。
6. 管理画面のカテゴリ順ソートは日本語文字列順であり、出力順定義とは一致しない。
7. `admin.html` と `README.md` に旧8カテゴリの説明が残っている。
8. `negative_tags` は25件あり、タグ本体の検索分類と出力先の意味が混在している。現在の出力振り分けはネガティブ指定を優先するが、タグ分類自体の整理は未完了。

## 3. 正式な大分類

次の10区分を新しい設計上の基準とする。

| 順番 | 大分類 | 役割 |
|---:|---|---|
| 1 | 品質・スコア | 品質評価、解像度、精細度、スコア |
| 2 | 人物・キャラクター | 人物属性、身体、顔、髪、作品・キャラクター |
| 3 | 服装・装飾 | 衣服、下着、露出、装飾品、小物 |
| 4 | ポーズ・姿勢 | 静的な姿勢、身体の向き、手足や身体の配置 |
| 5 | 動作・接触 | 動作、身体・衣服・物・他者への接触 |
| 6 | 背景・環境 | 場所、室内外、自然、天候、時間帯、環境 |
| 7 | 構図・カメラ | 視点、角度、距離、フレーミング、構図 |
| 8 | 画風・描写 | 画風、描画技法、媒体、レンダリング表現 |
| 9 | 光・色彩・演出 | 照明、影、色調、雰囲気、視覚効果 |
| 10 | ネガティブ | ネガティブ出力の選択・管理用区分 |

ネガティブは通常の意味分類と混同しない。タグの意味上の分類は上記1〜9のいずれか（または要確認）とし、ネガティブ出力先は独立した属性として保持する。UI上は10番目の「ネガティブ」区分からネガティブ対象タグを選択できるようにしてよいが、タグの意味分類をネガティブへ強制移動させない。

## 4. 分類・属性の分離ルール

各タグは概念上、次の独立した情報を持つ。

- **意味分類**: 1〜9の大分類と小分類。タグが何を表すかを示す。
- **出力先**: positive / negative。プロンプトのどちらへ出すかを示す。既存 `negative_tags` は移行時にこの属性へ統合する。
- **出力順**: 大分類順・小分類順に加え、品質タグには明示的な優先順位を持たせる。
- **検索属性**: 色などの属性、作品タイトルとキャラクターの親子関係、同義語・検索語など。タグ本体を不用意に改変しない。
- **レビュー状態**: 確定 / 要確認 / 要修正。未確認データを自動で確定扱いにしない。

### 品質タグ

品質・スコアの小分類は以下を基準とする。

- 高品質・傑作
- 解像度・精細度
- スコア
- 低品質・ノイズ

`masterpiece`, `best quality`, `high quality` などの高品質タグは、カテゴリ別出力のON/OFFに関係なくポジティブ出力の先頭に配置する。低品質・ノイズ系タグは意味分類を品質・スコアに置きつつ、ネガティブ出力指定がある場合はネガティブ側だけへ出す。低品質タグを自動的に全件ネガティブ指定しない。

### キャラクター

人物・キャラクター内に作品・シリーズとキャラクターの階層を持つ。作品名とキャラクターは独立して選択でき、親の作品名を選んでも配下キャラクターを自動選択しない。人物数指定（例: `2girls`）はキャラクター階層へ入れない。

### 色属性

`blue dress` のような複合タグは、意味を損なわない場合に限り「対象タグ + 色属性」として検索可能にする。タグ本体の変更と属性メタデータは分離する。固有名詞・作品名・慣用表現・意味が変化する複合語は機械的に分解しない。

## 5. 旧分類からの移行方針

旧分類名だけを根拠に一括変換しない。タグ単位で意味を確認し、次のように扱う。

| 旧分類 | 移行の考え方 |
|---|---|
| 人物 | 人物・キャラクターへ。人数、顔、髪、身体、種族などに再分割 |
| 作品・キャラクター | 人物・キャラクター内の作品階層へ |
| 服装 | 服装・装飾へ。衣服、下着、装飾、小物などに再分割 |
| ポーズ・動作 | 静的な姿勢はポーズ・姿勢、行為・接触は動作・接触へ分割 |
| シチュエーション | 意味に応じて動作・接触、背景・環境、人物・キャラクター等へ個別判定 |
| 背景・場所 | 背景・環境へ。場所、施設、自然、時間・天候等に再分割 |
| 構図・視点 | 構図・カメラへ |
| 画風・品質 | 画風・描写と品質・スコアへ分割 |
| 光・色彩 | 光・色彩・演出へ |
| 成人向け | 成人向けという単一の意味分類を維持せず、タグの意味に応じて1〜9へ分類。必要な年齢レーティングは独立属性として扱う |
| その他 | 動物・物・自然物・記号等の意味を確認して個別分類 |
| 未分類 | 全件レビュー対象。自動で一つのカテゴリへ押し込まない |

## 6. 監査・移行の段階

### Phase A — 分類辞書の設計
- 10大分類と小分類の確定。
- 旧分類から新分類への暫定対応表を作成。
- 各タグに意味分類・出力先・レビュー状態を持たせるデータ形式を設計。
- 既存4項目配列は維持し、追加情報は別JSONで管理する。

### Phase B — 高確度タグの再分類
- 品質・スコア35件を個別確認。
- 旧分類の明確なタグから移行。
- 作品名・キャラクター名の階層を整理。
- 既存タグを削除・改名せず、分類だけを変更する。

### Phase C — 未分類5,161件の段階的レビュー
- 意味の明確なタグをカテゴリへ割り当てる。
- 顔文字・記号・作者名・シリーズ名などは適切な専用小分類または検索専用区分を検討。
- 判断できないものは要確認として残す。
- バッチ単位で候補・理由・確信度を保存し、レビュー可能にする。

### Phase D — 日本語訳・タグ品質
- 空欄・英語のままの187件を優先確認。
- 直訳誤り、固有名詞、意味のずれ、表記揺れを監査。
- 英語タグの変更は必要性と生成モデル上の用法を確認してから行う。
- 意味的重複・同義語・別名を確認する。

### Phase E — 出力・UI統合
- 検索、選択、管理、出力で同じカテゴリ定義を参照。
- 品質タグの優先順位をカテゴリ別出力の有無にかかわらず適用。
- positive / negative を独立出力。
- コピー、TXT保存、手動編集、Undo / Redoを回帰テスト。
- 管理画面の並び替えも共通定義に従う。

## 7. 安全な移行条件

- `data/tags.json` の既存タグ件数と4項目配列を無断で破壊しない。
- 自動分類は候補として出し、低確信度は要確認にする。
- 元データと変更前後の差分を追跡できるようにする。
- ネガティブ指定と意味分類を同じフィールドで管理しない。
- `text`, `watermark`, `signature`, `multiple views` 等はポジティブ用途もあり得るため、固定的にネガティブ専用と断定しない。
- タグ本体の改名・削除は分類変更と別のレビューにする。
- 既存機能の回帰テストとタグ件数検証が通るまで main にマージしない。

## 8. この監査時点での未確認事項

- 11,047件すべての意味分類と日本語訳の正確性。
- 187件以外の日本語訳の自然さ・適切さ。
- 意味的重複・別名・タグのモデル依存性。
- 作品タイトルとキャラクターの完全な対応関係。
- 色属性へ安全に分離できる複合タグの全件。
- 25件のネガティブ指定の妥当性と、追加すべき候補。
- 既存タグ全件に対する新小分類の最終確定。

この文書は監査ベースラインと移行設計であり、タグ本体・既存分類データを変更したものではない。
