# Prompt Tag Dictionary

画像生成向けの英語タグを日本語で探し、意味や分類を確認しながら選択して、プロンプトを組み立てるためのブラウザ用タグ辞典です。

**公開ページ:** https://menosgrande.github.io/prompt-tag-dictionary/

## 主な機能

- 日本語・英語によるタグ検索
- 分類をたどってタグを閲覧
- タグの選択・解除とプロンプトの組み立て
- カテゴリ別・全タグの出力
- 作品・シリーズごとのキャラクター閲覧
- カテゴリコメントの日本語・英語切り替え
- タグの追加・編集などの管理機能
- JSONやPerchance形式のデータ取り込み

※機能の実装状況とブラウザでの動作確認状況は同一ではありません。未確認の項目を動作保証済みとして扱いません。

## 使い方

1. [公開ページ](https://menosgrande.github.io/prompt-tag-dictionary/)を開きます。
2. 日本語または英語でタグを検索するか、分類から目的のタグを探します。
3. 使用したいタグを選択します。
4. 組み立てたプロンプトを確認し、コピーまたは保存します。

## データと分類について

辞書データの唯一の正本は `data/dictionary-data.json` です。CSVは一括確認・編集用の入出力形式であり、独立した正本ではありません。古い分割JSONや過去の作業用ファイルを現行データの正本として使用しません。

分類体系やタグの確認状態は継続的に整備しています。画面に表示される分類は、すべてのタグについて意味上の正しさが確定したことを示すものではありません。翻訳・分類・表現レベルの確認状態はそれぞれ独立して扱い、未確認・要確認を確定済みと混同しません。

データの編集・翻訳確認・分類・表現レベル・CSV入出力・GitHubへの反映手順については、[データ整備・運用の正式方針](docs/DATA_MAINTENANCE_POLICY.md)を参照してください。

## 開発・作業状況

- 現在のデータ整備状況と、CSVから正本JSONへの反映待ち項目は[実装バックログ](docs/implementation-backlog.md)で管理しています。
- 特定日時の件数や候補一覧は監査レポートに記録します。履歴資料の数値を現在値として流用せず、作業開始時にGitHubの最新ブランチ・コミット・正本を確認します。
- 過去の監査資料は調査履歴として保持し、現行ルールは上記の正式方針に一本化します。

このリポジトリは静的ファイルで構成されています。ローカルで確認する場合は、リポジトリのルートを静的ファイルサーバーで配信して `index.html` を開いてください。

### GitHub Pagesで公開する場合

リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/(root)** に設定します。保存後、GitHub Pagesの公開URLからアクセスできます。静的ファイル構成のため、ビルド用のGitHub Actionsは必要ありません。

## データ出典・利用条件

一部の日本語訳の補完では、外部の公開翻訳データを参照しています。ただし、翻訳参照元のライセンス表示は、元のタグ一覧や本リポジトリに含まれるすべてのデータの利用・再配布条件を保証するものではありません。

元データの取得元・取得時点・再配布条件の一部は未確認です。利用条件を確認できていないデータについて、再配布可能であるとは断定しません。公開・再配布にあたっては、各データの出典と利用条件を個別に確認してください。
