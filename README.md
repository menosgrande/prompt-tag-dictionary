# Prompt Tag Dictionary

画像生成に使うタグを日本語・英語で探し、分類をたどって確認し、選択したタグからプロンプトを組み立てるブラウザ用ツールです。

## 現在の初期版

- 日本語・英語のタグ検索
- タグ一覧を100件単位で表示し、検索結果をページ移動
- 現行の18意味分類案と小分類（2階層）によるブラウズ（分類体系は監査中・最終確定前）。人物の身体的特徴とキャラクター・作品情報を分離し、ネガティブは品質カテゴリ内に表示しつつ出力先は分離
- タグ選択、選択解除、プロンプト出力
- 作品・シリーズ別にキャラクターをまとめて閲覧し、作品タグと各キャラクターを個別選択
- 全タグの一括出力／カテゴリ別出力
- カテゴリコメントの日本語・英語切り替え、コメント形式の切り替え
- 大分類・小分類・詳細分類を指定したタグの追加、TXT保存
- JSONとPerchance形式のJavaScript / テキストからタグデータを取り込み
- 読み込んだデータと選択状態をブラウザのローカルストレージに保存

## 実装状況・保留項目

全体の実装状況、未完了作業、受け入れ条件は [docs/implementation-backlog.md](docs/implementation-backlog.md) に集約します。実装済み・監査済み・ブラウザ確認済みを区別し、未確認を完了扱いしません。

### プロンプト出力カテゴリ順

カテゴリ別出力は現行実装では18区分です。分類体系・出力順・タグ別例外は `data/dictionary-data.json` に統合して保持します。分類境界は引き続き監査対象であり、実装済みであることを意味上の正しさの保証とは扱いません。

1. 品質・ネガティブ
2. 人数・人物構成
3. キャラクター・作品
4. 人物の特徴
5. 顔・表情
6. 髪・頭部
7. 服装・装飾
8. ポーズ・姿勢
9. 動作・接触
10. 状態・状況
11. 背景・場所
12. 家具・設備・物品
13. 乗り物
14. 構図・カメラ
15. 画風・描写
16. 光・演出
17. 生物・動植物
18. 文字・記号

通常画面のカテゴリ一覧とプロンプト出力は、現行の18分類案を参照します。これは実装上の現状であり、分類体系が最終承認済みであることを意味しません。既存の旧分類は表示時に読み替えますが、タグ本体の分類値は一括更新していません。

出力順は正本 `data/dictionary-data.json` 内の `promptOrder.categories[].order` で管理します。検索用の意味分類体系と出力順は同じ正本内で同期し、監査スクリプトで18カテゴリの順序一致を検査します。管理画面のローカル編集は、正本へ反映する前にエクスポート内容の検証が必要です。


### 仮分類の自動適用

分類候補はタグ行のメタデータとして正本内に保持します。`classificationCandidates` はタグ行の分類メタデータから導出する索引であり、独立した正本ではありません。

## 起動

依存パッケージやビルド工程はありません。ローカルでは静的ファイルサーバーから index.html を開きます。GitHub Pagesで公開する場合は、リポジトリの Settings → Pages → Build and deployment → Source で「Deploy from a branch」を選び、Branch を「main」、フォルダを「/(root)」に設定して保存してください。このリポジトリは静的ファイルだけで構成されているため、GitHub Actions のビルドやデプロイ処理は不要です。公開設定後は main ブランチへの変更が Pages に反映されます。

## 手元のタグデータを読み込む

1. アプリを開き、右上の「データを読み込む」を押します。
2. tags-full.json（英語タグ一覧）と tags-ja-progress.json（日本語訳データ）を同時に選択します。
3. 分類情報が入ったPerchanceのソースJavaScript / テキストもあれば、同時に選択します。
4. 「読み込む」を実行します。英語タグと翻訳の対応を統合し、タグの重複をまとめます。

2026-11-04時点の正本 `data/dictionary-data.json` には10,995件を収録しています。分類値が未分類のタグは3,343件、日本語欄が空のタグは7件です。分類候補メタデータは976件（暫定970件、要確認6件）で、すべて対応するタグ行のメタデータと同期させます。未分類・未訳・暫定は品質上の確認待ちであり、誤りと断定した件数ではありません。

## 辞書全体の表示方針

- 初期表示は人物の詳細分類を自動展開せず、大分類全体から選べる状態にします。
- 大分類は人物だけに偏らないよう、背景・場所、構図、画風、光・色彩など創作時に使う分野を続けて表示します。
- 検索語がない場合、英字で始まるタグ、数字で始まるタグ、記号で始まるタグの順に並べ、顔文字などの記号タグが一覧の先頭を占めないようにします。
- 作品・ゲーム・アニメなどの固有名詞候補は「作品・キャラクター」に分離します。括弧内の作品名・シリーズ名が既知のタグをルールで仮分類しており、括弧付きタグすべてをアニメ系と断定するものではありません。
- セット追加は人物だけでなく、風景、構図・ライティング、画風・品質の入口を用意します。
- これは表示順の改善であり、タグの分類データ自体を正しいと認定するものではありません。仮分類・未分類は引き続き要確認です。

## データの整理方針

タグ本体と翻訳・分類メタデータ、分類体系、出力順、タググループ、NSFW確認候補は `data/dictionary-data.json` を唯一の正本として管理します。タグ行は基本4項目配列を維持し、必要な行のみ第5〜7項目に詳細・別名・レビュー用メタデータを持ちます。変更履歴はGitのコミット履歴で追跡し、独立した変更履歴JSONは保持しません。

翻訳品質の初回監査結果と候補一覧は [docs/translation-quality-audit.md](docs/translation-quality-audit.md) を参照してください。監査候補は誤訳の確定ではなく、原文・現行訳・検出理由を確認するためのリストです。

- 元データ：取得時の形式と出典情報を保持する領域（今後整備）
- 整理済み辞典：tag、ja、category、aliases、keywords、explanation、related、preview を持つJSON
- 画像：今後 assets/previews/ 等に分離
- 追加・修正：元データを直接書き換えず、辞典用データに反映する方針

タグ分類は初期版の仮分類を含みます。分類の精度とタグごとの日本語説明は段階的に整備します。

## データ品質監査と統合ルール

- 出典の現状は正本 `data/dictionary-data.json` の `sourceInfo` に記録します。過去データの取得元URL・取得日・タグごとの出典は復元できないものがあるため、推測で補いません。
- 初期データは4項目の配列（tag、ja、major、minor）に統一しています。アプリの読み込み時にも旧形式を正規化します。
- 複数ファイルの同名タグを統合するときは、空欄だけを補完し、すでにある日本語訳・分類を自動で上書きしません。異なる訳や分類が競合した件数を読み込み結果に表示します。
- 読み込むファイルはファイル名順で処理します。同じファイルセットなら結果が順不同にならないようにします。競合の正誤は自動判定せず、必要に応じて確認してください。
- 既存ブラウザ保存データは起動時に同梱データと統合します。旧データや同梱データ由来の項目は更新を取り込み、別ファイル由来・カスタム項目は保護します。
- `scripts/build-dictionary-data.mjs --check` は正本JSONのスキーマ・分類候補索引・カテゴリ順の整合性を検証します。旧 `data/tags.json` など複数ファイルからの再生成処理は廃止し、正本を別ファイルで上書きしません。タグ構造・分類・翻訳・グループもGitHub Actionsで監査します。
- この監査は構造の検査です。日本語訳や意味上の分類が正しいことを保証するものではありません。

## 日本語訳の補完に使用したデータ

翻訳の空欄を補うため、次の公開データを照合しました。元から入っていた日本語訳は維持し、空欄だけを補っています。

- [boorutan/booru-japanese-tag](https://github.com/boorutan/booru-japanese-tag) の `danbooru-jp.csv` と `danbooru-machine-jp.csv`。手作業訳と機械翻訳が含まれます。リポジトリのライセンス表示はMIT、著作権表示は `Copyright (c) 2024 boorutan` です。
- [PYU224/tagdb-updater](https://github.com/PYU224/tagdb-updater) の `dist/danbooru-jp.csv`。Danbooruのwiki別名やコミュニティ翻訳データを含み、正規の日本語名ではなく別名が選ばれる場合があります。今回の確認では上流のライセンス許諾を独立して確認できなかったため、MITとは断定せず、再配布条件は未確認として扱います。

boorutan側のMIT表記は上流リポジトリの宣言であり、Danbooru由来の元データや本リポジトリの全タグデータの利用条件を保証するものではありません。本リポジトリ自体にも現時点でルートのLICENSEファイルはありません。

これらの出典に基づく追加訳は全件を人手で検証したものではありません。固有名詞、別名、表現が曖昧なタグには誤訳が残る可能性があります。また、この翻訳データの出典を記録したことは、元のタグ一覧そのものの取得元・再配布条件が確認済みであることを意味しません。公開・再配布時には、各データの利用条件を別途確認してください。
