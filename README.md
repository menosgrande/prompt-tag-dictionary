# Prompt Tag Dictionary

画像生成に使うタグを日本語・英語で探し、分類をたどって確認し、選択したタグからプロンプトを組み立てるブラウザ用ツールです。

## 現在の初期版

- 日本語・英語のタグ検索
- 大分類・小分類によるブラウズ
- タグ選択、選択解除、プロンプト出力
- 全タグの一括出力／カテゴリ別出力
- カテゴリコメントの日本語・英語切り替え、コメント形式の切り替え
- タグの追加、TXT保存
- JSONとPerchance形式のJavaScript / テキストからタグデータを取り込み
- 読み込んだデータと選択状態をブラウザのローカルストレージに保存

## 起動

依存パッケージやビルド工程はありません。ローカルでは静的ファイルサーバーから index.html を開きます。GitHub Pagesで公開する場合は、リポジトリの Settings → Pages → Build and deployment → Source で GitHub Actions を選択してください。初回の有効化はGitHub側のリポジトリ設定で必要になる場合があります。その後、mainへのpushでデプロイワークフローが動きます。

## 手元のタグデータを読み込む

1. アプリを開き、右上の「データを読み込む」を押します。
2. tags-full.json（英語タグ一覧）と tags-ja-progress.json（日本語訳データ）を同時に選択します。
3. 分類情報が入ったPerchanceのソースJavaScript / テキストもあれば、同時に選択します。
4. 「読み込む」を実行します。英語タグと翻訳の対応を統合し、タグの重複をまとめます。

現時点では、手元の英語タグ一覧10,600件に、別ソースの分類付きタグ候補を統合した11,047件を data/tags.json に収録しています。日本語訳と分類は一部のタグのみです。元データの取得元・利用条件はまだ確定していません。追加データのインポートはブラウザ内で行われ、GitHub上のファイルそのものは変更しません。

## データの整理方針

- 元データ：取得時の形式と出典情報を保持する領域（今後整備）
- 整理済み辞典：tag、ja、category、aliases、keywords、explanation、related、preview を持つJSON
- 画像：今後 assets/previews/ 等に分離
- 追加・修正：元データを直接書き換えず、辞典用データに反映する方針

タグ分類は初期版の仮分類を含みます。分類の精度とタグごとの日本語説明は段階的に整備します。

## データ出典・ライセンス上の注意

初期の手元データはタグ一覧、訳語進捗、Perchance用オートコンプリートのファイルです。元データの取得元・取得日時・再配布条件はまだ確定できていません。第三者のデータをリポジトリに一括収録したり公開配布したりする前に、各データの利用条件を確認してください。このリポジトリは、出典やライセンスの確認が済んだと断定しません。
